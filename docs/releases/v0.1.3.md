# Canon 2900 Driver - MacLife v0.1.3

[**Tải Canon-LBP2900-ML-0.1.3.pkg**](https://github.com/maclifevn/Canon-2900-Driver-MacLife/releases/download/v0.1.3/Canon-LBP2900-ML-0.1.3.pkg)

Bản thử nghiệm cho **Canon LBP2900 thường**, nối USB trực tiếp với **Mac Apple Silicon chạy macOS 26 hoặc 27**. Bộ cài đã ký Developer ID, được Apple notarize và gắn ticket. Gatekeeper chấp nhận bộ cài.

## Thay đổi

- Giữ phiên USB giữa các lệnh in để xử lý tình trạng các lệnh gửi sau bị kẹt.
- Kiểm tra phản hồi giải phóng lệnh CAPT và ghép lại phản hồi USB bị chia nhỏ.
- Giữ hàng đợi **Canon LBP2900** khi cài đè v0.1.0 đến v0.1.2.

## Cài đặt và kiểm tra

Chờ các lệnh đang in hoàn tất, cắm USB và bật máy in, rồi mở file `.pkg` và làm theo Installer. macOS sẽ hỏi quyền quản trị. [Hướng dẫn cài và gỡ](https://github.com/maclifevn/Canon-2900-Driver-MacLife/releases/download/v0.1.3/INSTALL.md)

Đã kiểm tra tám lệnh in riêng, mỗi lệnh hai trang, với máy in mô phỏng trên macOS 27.0.1. Việc in liên tiếp trên LBP2900 thật vẫn cần xác nhận. Có thể đối chiếu file tải về với [SHA256SUMS](https://github.com/maclifevn/Canon-2900-Driver-MacLife/releases/download/v0.1.3/SHA256SUMS) và xem [báo cáo kiểm tra](https://github.com/maclifevn/Canon-2900-Driver-MacLife/releases/download/v0.1.3/VERIFICATION.txt).

# Canon 2900 Driver - MacLife v0.1.2

[**Tải bộ cài Canon-LBP2900-ML-0.1.2.pkg**](https://github.com/maclifevn/Canon-2900-Driver-MacLife/releases/download/v0.1.2/Canon-LBP2900-ML-0.1.2.pkg)

Driver cộng đồng cho **Canon LBP2900 thường**, kết nối USB trực tiếp với **Mac Apple Silicon (ARM64) chạy macOS 26 hoặc 27**.

Bộ cài hiện tại không cài được trên macOS 15.x; binary yêu cầu tối thiểu macOS 26.0.

## Cài đặt

Tải file `.pkg`, cắm USB và bật máy in, rồi mở bộ cài và làm theo Installer. Bộ cài đã ký Developer ID, được Apple notarize và gắn ticket; macOS vẫn hỏi quyền quản trị để cài driver. Có thể cài đè bản 0.1.0 hoặc 0.1.1. Tên máy in hiển thị là **Canon LBP2900**.

## Thay đổi

- Cập nhật màn hình đầu installer theo nội dung MacLife và thêm liên kết [cộng đồng MacLife và Đồng bọn](https://www.facebook.com/groups/maclife.vn).
- Bỏ chữ OpenCAPT khỏi tên máy in hiển thị; giữ hàng đợi cũ để cập nhật khi cài đè.
- Ký hai thành phần driver bằng Developer ID Application với hardened runtime và timestamp.
- Ký bộ cài bằng Developer ID Installer, notarize và gắn ticket Apple. Mã xử lý in giữ nguyên như bản 0.1.0 đã được người dùng xác nhận in thành công.
